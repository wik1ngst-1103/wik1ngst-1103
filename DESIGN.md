# Design System: wik1ngst-1103

## Overview

**Creative North Star: "The Quiet Character Screen"**

The profile is a game's character screen paused on a neutral panel: name plate, character sheet, loadout, quest log, player stats. Every card sits on GitHub's own surface tones so the page reads as part of GitHub rather than a widget pasted onto it, and the game identity comes from structure and three small devices (pixel headings, block cursors, a pixel helmet), not from colour. One amber, used sparingly, is the only hue on the page.

Density is calm and tabular. Information is laid out as label…value rows separated by hairlines, in two columns split down the middle of a 1000-unit card. Everything people read is set in Barlow; Press Start 2P appears only where a game would put its UI chrome, the handle and the section headings.

Every card is a fixed-width SVG generated by script, with every word converted to outlines, and each ships as a light and a dark variant swapped by `<picture>` and `prefers-color-scheme`. The system is defined by two parallel themes with identical roles, not by a single palette.

**Key Characteristics:**
- Neutral panels matched to GitHub light and dark; one amber accent per theme.
- 1.5px hairline card borders, 14px corners, no shadows.
- Pixel type for handle and headings only; Barlow for all reading text.
- Label…value rows with 1px hairline rules, values right-aligned.
- Monochrome Simple Icons in the text colour.
- Square amber block cursors as the game device; only the quest log's now-playing cursor blinks.

## Colors

Two neutral themes with the same six roles each, and a single amber that shifts from lantern-bright on dark to bronze on light for contrast.

### Primary
- **Lantern Amber** (dark) / **Bronze Amber** (light): the only accent. Used for pixel section headings, block cursors, the helmet's horns, filled bar segments and the contribution-snake dot ramp. Nothing else is amber.

### Neutral
- **Night Panel** (dark) / **Paper Panel** (light): card fill, matched to GitHub's own subtle canvas.
- **Night Hairline** / **Paper Hairline**: the 1.5px card stroke, the 1.5px column divider and the 1px row rules.
- **Frost Text** / **Ink Text**: names, values, quest names, icons, the helmet's body and the handle.
- **Slate Muted** / **Pewter Muted**: row keys, column subheads, the stack line, languages, dates, percentages, the helmet's visor band.
- **Night Empty Slot** / **Paper Empty Slot**: unfilled segments in the language bars.

### Named Rules
**The One Amber Rule.** Amber marks game chrome and progress only: headings, cursors, horns, filled segments, snake dots. Body text, values, icons and borders never take it.

**The Paired Theme Rule.** Every card ships as a light and a dark variant with identical layout; only the role colours swap. Never design a card for one theme alone.

**The No Language Colours Rule.** Language bars and icons ignore GitHub's per-language and brand colours. Bars are amber on empty-slot; icons are text-coloured.

## Typography

**Display Font:** Press Start 2P (outlined into paths; no fallback needed)
**Body Font:** Barlow Medium and Barlow SemiBold (outlined into paths)

**Character:** A blocky 8-bit face supplies the game chrome; a clean grotesque carries every fact, so the joke never costs legibility.

Sizes are set by cap height in the 1000-unit SVG coordinate space; the frontmatter `fontSize` is the equivalent em size (Press Start 2P cap 875/1000, Barlow cap 700/1000). On screen the cards scale to the README width, roughly 0.88× on desktop and 0.36× at 390px.

### Hierarchy
- **Handle** (Press Start 2P, cap 34, tracking 2): the `WIK1NGST` handle on the name plate only, in text colour, followed by the block cursor.
- **Headline** (Press Start 2P, cap 16, tracking 1): section headings (CHARACTER, LOADOUT, QUEST LOG, PLAYER STATS, TOP LANGUAGES, CONTRIBUTIONS), always amber, baseline 62 from the card top.
- **Title** (Barlow SemiBold, cap 24): the real name on the name plate.
- **Value** (Barlow SemiBold, cap 19–20): row values, loadout labels, quest names, stat numbers; right-aligned when paired with a key.
- **Body** (Barlow Medium, cap 17): the stack line, stat row labels.
- **Body small** (Barlow Medium/SemiBold, cap 16): languages, dates, descriptions, percentages, language names in bars.
- **Label** (Barlow Medium, cap 17, tracking 1, uppercase): row keys (CLASS, SPAWN), column subheads (LAST 12 MONTHS, ALL TIME) and the NOW PLAYING legend, always muted.

### Named Rules
**The Pixel Chrome Rule.** Press Start 2P is for the handle and section headings only. Anything a visitor reads for meaning is Barlow.

**The Outlines Only Rule.** No live `<text>` and no web-font references. Every glyph is drawn to a path at build time so the SVG renders identically inside GitHub's image sandbox. Characters the face can't draw are dropped, and long strings are fitted with an ellipsis rather than overflowing.

## Layout

Each section is its own full-width card, 1000 units wide, stacked vertically in the README and scaled to 100% width. Cards share a 40-unit inset (the name plate uses 44). Two-column cards split at x=500: the left column runs 40→460, the right 540→960, giving an 80-unit gutter, with a 1.5px vertical hairline on the split in the character sheet. Values right-align to 460 and 960.

Row rhythm: 54 units between rows in the character sheet and quest log, 46 in stat columns, 40 between language bars, each row followed by a 1px rule 18–22 units below its baseline (none after the last). Card heights are content-driven (header 220, sheet 316, stats 500, quests computed from row count).

The closing row is three 320×96 link cards, each placed at 32% width so they sit side by side at every viewport. The contribution section has no card: a 44-unit title strip carrying the pixel heading, then the snake grid directly on the page canvas.

There are no responsive variants: the SVGs scale proportionally, so all type shrinks with the viewport.

## Elevation & Depth

Flat. No shadows, glows or gradients anywhere. Separation comes from the panel tone sitting one step off GitHub's page canvas plus the 1.5px hairline stroke. Inside cards, structure is carried by 1px hairline rules and the vertical divider, never by nested surfaces.

**The Hairline Not Shadow Rule.** Depth is a tone step and a hairline. If a surface needs to read as separate, give it the card stroke; never a shadow.

## Shapes

Cards and link cards: softly rounded rectangles (14px) with a 1.5px hairline stroke, inset 1 unit so the stroke isn't clipped. Game devices are square-cornered: block cursors (0px), the helmet sprite's 7-unit pixel grid, and bar segments with only a 1px nick of rounding. Rules are straight 1px lines.

## Components

### Cards / Containers
Quiet panels that hold one section each.
- **Corner Style:** 14px.
- **Background:** Night Panel / Paper Panel.
- **Shadow Strategy:** none (see Elevation & Depth).
- **Border:** 1.5px Night Hairline / Paper Hairline.
- **Internal Padding:** 40 units; heading baseline at 62.

### Section Heading
Amber Press Start 2P at cap 16, left-aligned at the card inset. It is the section's only title; nothing sits above it.

### Label…Value Row
The core data pattern. A muted tracked-caps key (or a text-colour Barlow label in stat cards) at the left edge, a SemiBold value right-aligned to the column edge, and a 1px hairline rule beneath every row except the last. In the loadout the key is replaced by one or two 24-unit monochrome Simple Icons, 34 units apart.

### Block Cursor
A solid amber rectangle with square corners. On the name plate it follows the handle (20×34) and is static. In the quest log a 12×20 cursor marks the now-playing row and is the only animated element: opacity blinks on a 1.2s step-end loop, disabled under `prefers-reduced-motion: reduce`. A static 10×17 cursor beside the muted NOW PLAYING label acts as the legend.

### Segmented Bar
Twenty 8×14 segments on an 11-unit pitch, each worth 2.5%, at least one always filled. Filled segments are amber, the rest Empty Slot; the percentage sits right-aligned in muted small body.

### Quest Row
Text-colour SemiBold repository name at x=66 (leaving room for the cursor), muted language at x=640, muted date right-aligned. The first row adds its description on a second muted line.

### Link Card
320×96 card with a 28-unit monochrome Simple Icon at the left and a SemiBold label (cap 18, shrunk to fit), wrapped in a link. Three sit in one row at 32% width each.

### Pixel Helmet (signature)
A 16×13 pixel helmet drawn at 7 units per pixel at the right of the name plate: amber horns, text-colour shell and cheek guards, a muted visor band. It is the only illustration in the system.

### Contribution Snake
Generated by Platane/snk. The snake is text colour (#1F2328 light, #E6EDF3 dark); the dot ramp runs from an empty neutral through amber tints to the theme amber (light #EBEEF1 → #9A6700, dark #161B22 → #E3B341).

## Do's and Don'ts

### Do:
- **Do** generate every card from the THEMES tokens in `scripts/build_assets.py`, in both light and dark, at 1000 units wide.
- **Do** outline every glyph into paths and give each SVG a `<title>` and `aria-label` that states its facts.
- **Do** lay data out as label…value rows with 1px hairline rules, values right-aligned to the column edge.
- **Do** keep amber to headings, cursors, the helmet's horns, filled bar segments and the snake ramp.
- **Do** draw icons from Simple Icons in the text colour.
- **Do** honour `prefers-reduced-motion` on any animation.

### Don't:
- **Don't** add a second accent hue or saturated fills; the user rejected the colourful arcade cabinet as hard to look at.
- **Don't** use Press Start 2P for anything a visitor reads for meaning.
- **Don't** add shadows, glows or gradients to cards.
- **Don't** use GitHub language colours or brand-coloured icons.
- **Don't** animate anything besides the quest log's now-playing cursor and the snake; the name-plate cursor stays static.
- **Don't** reference live fonts or `<text>` elements in the SVGs.
